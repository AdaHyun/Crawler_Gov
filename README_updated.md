# Public Health Document Crawler Dataset README

本项目用于爬取和整理公共卫生相关官方网站中的政策文件、疫情信息、科普文章、监测报告、统计数据和公开出版物等资料。当前数据主要以结构化 JSONL 文件保存，并配套保留附件、图片、运行日志和统计文件，便于后续进行公共卫生文本分析、政策文件整理、知识库构建或大语言模型数据集构建。

当前覆盖的数据来源包括：

- 中国疾病预防控制中心
- 中国疾控中心慢病中心
- 国家疾病预防控制局
- 国家卫生健康委员会
- 国家心理健康和精神卫生防治中心
- 广东省卫生健康委员会
- World Health Organization

------

## 1. 项目目标

本项目的主要目标是从公共卫生相关官方网站中自动化采集公开文档数据，包括：

1. 政策法规类文件
2. 疾病预防控制标准
3. 疫情信息与监测报告
4. 传染病防控资料
5. 疾控科普文章
6. 健康生活方式科普内容
7. 统计数据与工作通知
8. 心理健康与精神卫生相关资料
9. 国际公共卫生出版物

采集后的数据统一保存为结构化文件，便于后续清洗、检索、分析和建模使用。

## 4. 项目目录结构

项目的主要目录结构如下：

```text
nhc_crawler/
├── config/
│   └── sites.json                         # 爬取站点与栏目配置
├── data/
│   ├── output/                            # 结构化输出数据，主要为 JSONL
│   ├── attachments/                       # 下载后的附件文件
│   ├── images/                            # 下载后的正文图片
│   ├── raw_html/                          # 原始网页 HTML，主要用于排查解析问题
│   ├── logs/                              # 爬虫运行日志
├── scripts/
│   ├── export_attachment_stats.py         # 统计附件下载情况
│   └── stats_by_institution_project.py    # 按机构、栏目及分类字段统计数据情况
├── src/
│   ├── main.py                            # 项目主入口
│   └── parser/                            # 不同网站的列表页/详情页解析模块
├── .gitignore
└── README.md
```

## 6. data 目录文件说明与查阅提示

### 6.1 `data/output/`：结构化正文数据

该目录是最主要的数据入口。每个 `.jsonl` 文件中，每一行是一条独立文档记录。建议优先查看该目录。

查阅建议：

1. 想看某个机构的正文内容，直接打开对应的 `*_all_documents.jsonl`。
2. 想按栏目筛选，查看字段 `source.channel_name`。
3. 想按政策类别或主题筛选，查看字段 `classification.policy_category`、`classification.topic_tags`。
4. 想查看附件是否下载，查看字段 `attachments[].download_status` 和 `attachments[].local_path`。
5. JSONL 文件较大时，不建议直接用 Word 打开，建议使用 VS Code、Python、Pandas 或文本编辑器查看。

### 6.2 `data/attachments/`：附件文件

该目录保存从网页中下载的 PDF、Word、Excel 等附件。附件通常按照机构、栏目和文章标题分级保存。

查阅建议：

1. 优先通过 JSONL 中的 `attachments[].local_path` 定位对应附件。
2. 如果页面正文较短，但附件较多，重点查看附件内容，因为部分政策或报告全文可能在附件中。
3. 同一篇文章可能有多个附件，需结合 `attachments[].name` 判断附件含义。

### 6.3 `data/images/`：正文图片

该目录保存正文中识别并下载的图片，主要用于保留科普文章、图示说明、政策解读图等视觉材料。

查阅建议：

1. 图片路径通常可在 JSONL 的 `images[].local_path` 中找到。
2. 如果只做纯文本分析，可以暂时不处理该目录。
3. 如果做多模态数据集或网页还原，需要结合 `content.body_html` 和图片路径一起查看。

### 6.4 `data/raw_html/`：原始网页 HTML

该目录保存部分网页的原始 HTML，主要用于排查页面解析错误、字段缺失、正文抽取异常等问题。

查阅建议：

1. 正常查看数据时不需要优先看该目录。
2. 如果发现某条 JSONL 记录正文为空、附件缺失或标题异常，可以回到对应原始 HTML 排查。
3. 该目录通常体积较大，不建议作为主要交付材料直接查看。

### 6.5 `data/logs/`：运行日志

该目录保存爬虫运行过程中的日志，包括请求状态、解析状态、下载状态和异常信息。

查阅建议：

1. 如果需要确认某次爬虫是否正常完成，先查看最新日志。
2. 如果附件或图片下载失败，可以在日志中搜索 `failed`、`error`、`timeout`、`404` 等关键词。
3. 如果某个机构数据量异常偏少，也可以通过日志确认是否被网站拦截、分页结束或页面结构变化。

## 7. 数据格式说明

输出数据采用 JSONL 格式，即每一行是一个独立的 JSON 对象。该格式适合大规模文本数据存储，也便于后续使用 Python、Pandas、数据库或大语言模型训练管道进行处理。

单条数据通常包含以下字段：

```json
{
  "doc_id": "文章唯一编号",
  "title": "文章标题",
  "url": "原文链接",

  "source": {
    "site_name": "数据来源机构",
    "site_domain": "来源网站域名",
    "site_url": "来源网站首页",
    "channel_name": "栏目名称",
    "channel_url": "栏目链接"
  },

  "organization": {
    "source_department": "来源部门 / 所属司局",
    "issuing_authority": ["发文机构"],
    "joint_departments": ["联合发文部门"]
  },

  "classification": {
    "policy_level": "政策层级",
    "document_type": "文档类型",
    "policy_category": "政策分类",
    "topic_tags": ["主题标签"],
    "target_region": "适用地区"
  },

  "dates": {
    "publish_date": "发布日期",
    "crawl_date": "爬取日期"
  },

  "content": {
    "body_text": "正文纯文本内容",
    "body_html": "正文 HTML 内容"
  },

  "attachments": [
    {
      "name": "附件文件名",
      "url": "附件下载链接",
      "file_type": "附件类型",
      "local_path": "附件本地保存路径",
      "download_status": "附件下载状态"
    }
  ],

  "images": [
    {
      "url": "图片链接",
      "local_path": "图片本地保存路径",
      "download_status": "图片下载状态"
    }
  ],

  "crawl": {
    "crawler_name": "爬虫名称",
    "crawl_status": "爬取状态",
    "http_status": "HTTP 状态码",
    "raw_html_path": "原始 HTML 保存路径",
    "text_hash": "正文内容哈希值",
    "error_message": "错误信息"
  },

  "raw": {
    "raw_title": "网页原始标题",
    "raw_date": "网页原始日期",
    "raw_source": "网页原始来源"
  }
}
```

## 8. Git 上传说明

本项目仅上传必要代码、结构化输出文件和日志文件。以下内容通常不会上传到 GitHub：

```text
data/attachments/
data/images/
data/raw_html/
```

如果需要把完整 data 数据包交付给 mentor，可以单独打包 `data/` 目录；如果只需要代码审阅，则不建议上传大型附件和原始网页文件。

## 9. 使用场景

本项目采集的数据可用于：

1. 公共卫生政策文本分析
2. 疫情信息与传染病报告整理
3. 疾病预防控制知识库构建
4. 中文公共卫生语料库建设
5. 政策法规与标准文件检索
6. 公共卫生问答系统或 RAG 系统开发
7. 大语言模型领域数据构建
8. 公共卫生中英文资料对照与扩展分析

------

## 10. 注意事项

1. 本项目采集的数据均来自公开网站页面，仅用于学习、研究和数据分析。
2. 数据内容版权归原发布机构所有。
3. 若用于公开发布、模型训练或产品系统，应遵守对应网站的使用规范与数据合规要求。
4. 大型附件、网页原始 HTML、图片等文件体积较大，建议单独打包或使用云存储管理。
5. JSONL 中的 `local_path` 是本地路径，如移动数据包位置，可能需要根据新目录调整路径。
6. 数据清洗、附件文档解析、去重、质量过滤等工作可在该数据基础上继续进行。
